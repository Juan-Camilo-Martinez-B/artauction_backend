# OpenAPI v1

El api-gateway publica el contrato HTTP en tiempo de ejecucion:

- `GET /docs`: Swagger UI.
- `GET /docs-json`: el documento OpenAPI 3, apto para generar clientes o importarlo en Postman.

No hay un archivo generado en el repositorio: la fuente son los DTO y los controladores del gateway, los mismos que validan cada peticion, asi que el contrato no puede separarse del codigo. La e2e comprueba que las rutas que usa el frontend esten publicadas.

Autenticacion: bearer JWT de acceso. El refresh rota en `POST /auth/refresh` y no viaja en la URL.

Las obras con `visibility = PRIVATE` responden `404` a quien no es el vendedor. El catalogo publico lista obras `PUBLIC` en estado `APROBADO`, `PUBLICADA` o `EN_SUBASTA`. Una obra `VENDIDA` sale del catalogo.

Los errores tienen siempre la forma `{ statusCode, error, message }`. Un servicio caido responde 503 y un deadline vencido, 504.
